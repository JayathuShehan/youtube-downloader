YTDownloader

A small, fast YouTube downloader for Windows. Use it from CMD or from a web page on your own PC. Each file is downloaded over many connections at once, like IDM, and downloads can be paused and resumed.

ytd -url    →  download in the console (link → type → quality → download)
ytd -ui     →  open the web UI in your browser (http://localhost:8765)
Fast

8 connections per stream by default (up to 32). Video and audio download at the same time.

Pause / Resume

Continue later, even after closing the program or restarting the PC.

Up to 4K

Choose from the qualities the video really has, with the size of each.

Audio

Original M4A or Opus, or MP3 at 320, 192 or 128 kbps.

Not sure which you have? Open Settings → System → About and look at System type. Almost all PCs today are 64-bit.

32-bit Windows: YouTube needs Deno or Node.js to solve its JavaScript check, and neither of them supports 32-bit Windows anymore. On a real 32-bit PC, YouTube downloads may fail. The x86 build works fully on 64-bit Windows.

After downloading

  1. Extract the zip, e.g. to C:\Tools\YTDownloader\. If you downloaded only the exe, rename it to YTDownloader.exe. To use the short name ytd, put ytd.cmd from the zip next to it.
  2. Install the requirements: ffmpeg and Deno.
  3. Open CMD in that folder and run ytd -url or ytd -ui, or double-click YTDownloader.exe to open the web UI.
  4. Optional: add the folder to your PATH so ytd works from any folder. Go to Start → "Edit the system environment variables" → Environment Variables → Path → New.
Windows SmartScreen may warn you because the exe isn't code-signed. Click More info → Run anyway, or build it yourself with one-click setup.

One-click setup (from source)

Download the Source code (zip) from the Releases page, or clone the repository. Extract it, then double-click setup.bat. It does the following:

  1. Checks for Python 3.10+ and installs Python 3.12 with winget if it's missing (just for your user account, and added to PATH).
  2. Checks for ffmpeg and installs it with winget if it's missing.
  3. Checks for Deno or Node.js and installs Deno with winget if neither is found.
  4. Builds the program: creates a Python virtual environment, installs the packages and builds dist\YTDownloader.exe, with ytd.cmd next to it.
  5. Opens this documentation and the dist folder.

On 32-bit Windows it builds the 32-bit version into dist-x86\ instead.

Installing with winget accepts each package's license for you. If winget is missing, install App Installer from the Microsoft Store, or install Python, ffmpeg and Deno yourself, then run setup.bat again. If something fails, the window stays open so you can read the error.

Web UI

ytd -ui

Your browser opens http://localhost:8765. The page is only reachable from your own PC. Keep the console window open while downloading. Closing it stops the downloads, but their progress is saved.

  1. Video link: paste a link. The info loads automatically, or press Fetch. You'll see the thumbnail, title, channel and length.
  2. Type: choose Video or Audio.
  3. Quality: pick from the list. Each option shows its codec and estimated size.
  4. Save to: type a folder, or click Browse… to open the Windows folder picker. The default is your Downloads folder, and the last folder you used is remembered.
  5. Connections: 1, 4, 8, 16, 24 or 32 per stream.
  6. Start, Pause, Resume. After an error, Resume changes to Retry.

Progress panel

  • Overall progress bar and percentage
  • Current stage: getting info, downloading, merging, converting, completed
  • Downloaded / total size, speed, time left, active connections, quality
  • A bar for each stream (video and audio) showing every connection's segment filling up live
  • Show in folder when finished, which opens Explorer with the file selected
  • A Downloads this session list when you start more than one download

Pause and resume

While downloading, the program keeps two files in the save folder:

<Title> [<video id>].f<format>.part             ← the partly downloaded data
<Title> [<video id>].f<format>.part.ytd.json    ← which bytes are already done
  • Pause (button, P, Q or Ctrl+C) stops all connections and saves the progress file.
  • Resume continues from the saved byte positions.
  • After closing the program or a crash: run the same link with the same quality and the same folder, and it continues.
  • When the file is saved, both temporary files are deleted.

To give up on a paused download, delete its .part and .part.ytd.json files.

How it works

             ┌──────────────┐  stream links  ┌──────────────────────────────┐
  link ───►  │    yt-dlp    │ ─────────────► │ segmented downloader         │
             │ (extractor)  │                │  video: N parallel ranges ─┐ │
             └──────────────┘                │  audio: N parallel ranges ─┤ │
                    ▲  new link              └────────────────────────────┼─┘
                    └── when a link expires (HTTP 403/410)                ▼
                                                     ffmpeg: join / convert ──► final file
  1. Getting the streams: yt-dlp is used as a library, only to read the video info and find the direct stream links. It also handles YouTube's signature and JavaScript checks.
  2. Segmented downloading: a tiny Range: bytes=0-0 request finds the file size. The file is created at full size and split into N segments. Each connection downloads its segment in requests of up to 10 MB, because YouTube slows down very long single requests. When a connection finishes, it splits the largest remaining segment in half and takes the second half, so all connections stay busy.
  3. Video and audio at the same time: each stream has its own set of connections, so with 8 per stream, up to 16 run together.
  4. Joining / converting: ffmpeg -c copy joins the streams without re-encoding. Audio is re-encoded only for MP3.
  5. Errors: each connection retries with increasing waits. An expired link triggers a single refresh shared by all connections.

Why it's faster: YouTube limits the speed of each connection, and many connections together get close to your full internet speed. In testing on one connection, 1 connection reached about 5.4 MB/s and 16 connections about 9 MB/s, which was the full speed of that line.

Building from source

The easiest way is one-click setup. To do it by hand, you need Python 3.10+ on Windows:

git clone https://github.com/JayathuShehan/youtube-downloader.git
cd youtube-downloader
powershell -ExecutionPolicy Bypass -File build.ps1
CommandResult
build.ps164-bit build → dist\YTDownloader.exe
build.ps1 -Arch x8632-bit build → dist-x86\YTDownloader.exe (needs a 32-bit Python)
build.ps1 -Python C:\path\python.exeUses a specific Python

The script creates a virtual environment (.venv, or .venv-x86 for 32-bit), installs requirements.txt and PyInstaller, builds a single-file exe and copies ytd.cmd next to it.

To get a 32-bit Python, use the python.org "Windows installer (32-bit)", or run uv python install cpython-3.12-windows-x86-none.

Run without building

python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_ytd.py -url
.venv\Scripts\python run_ytd.py -ui

Keeping YouTube support up to date

YouTube changes often. If downloads stop working, update yt-dlp and build again:

.venv\Scripts\python -m pip install -U yt-dlp yt-dlp-ejs
powershell -ExecutionPolicy Bypass -File build.ps1

Troubleshooting

ProblemFix
'ytd' is not recognized...Run it from the folder with ytd.cmd and YTDownloader.exe, or add the folder to PATH. In PowerShell, use .\ytd.
ffmpeg was not foundPut ffmpeg.exe next to the exe, or run winget install Gyan.FFmpeg and open a new CMD window.
Formats missing, or download fails right awayInstall Deno (winget install DenoLand.Deno) or Node.js, then update yt-dlp.
YouTube keeps refusing the stream (HTTP 403)Use fewer connections (-c 4), wait a little and try again.
Private, age-restricted or members-only videoNot supported. These need a signed-in account.
Playlist linkOnly single videos are supported. A link with &list= downloads just that video.
Web UI doesn't openOpen http://localhost:8765 yourself. The console shows the port being used.
Slow downloadTry 16 connections. Your own internet speed is the upper limit.
SmartScreen warningThe exe isn't code-signed. Click More info → Run anyway, or build it yourself.
setup.bat says winget is missingInstall App Installer from the Microsoft Store, or install Python, ffmpeg and Deno yourself.
Setup installed something but can't find itClose the window and run setup.bat again, so it picks up the updated PATH.
