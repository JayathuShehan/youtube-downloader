# Code of Conduct

This project is open to everyone who wants to use it, report problems or help improve it. To keep it a friendly place, everyone taking part in issues, pull requests and discussions agrees to the following.

## Expected Behaviour

- Be respectful and patient, especially with people who are new
- Keep feedback about the code or the idea, not the person
- Accept that the maintainer makes the final decision on what gets merged
- Help others when you can

## Not Acceptable

- Insults, harassment, or personal or political attacks
- Discriminatory language or jokes of any kind
- Sharing someone's private information without permission
- Spam, advertising, or repeatedly posting off-topic content
- Asking for help downloading content you have no right to download, or posting links to pirated material

## Enforcement

The maintainer may edit or remove comments, lock conversations, close issues and pull requests, or block users who break these rules. Usually a warning comes first; serious or repeated problems can lead to a permanent block.

To report a problem with someone's behaviour, use GitHub's **Report content** option on the comment (the `...` menu), or contact the maintainer [JayathuShehan](https://github.com/JayathuShehan) through GitHub.

## Scope

These rules apply to everything in this repository: issues, pull requests, discussions, commit messages and code review.
